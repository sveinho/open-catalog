# User Lifetime Value (LTV)

LTV predicts the net profit contributed to the entire future relationship with a customer.

### Calculation
We calculate this by multiplying Average Order Value by Purchase Frequency. Refer to the [Revenue Data Dictionary](revenue-dictionary.md) for data schemas.
